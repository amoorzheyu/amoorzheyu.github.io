我从大学时期就开始在 [CSDN](https://szcyyds.blog.csdn.net/) 复盘自己学到的东西。那时候像只互联网小狗，刚学会一点什么，就急着写下来发出去。想法很简单，自己踩过的坑，能不能让另一个刚入门的人少踩一次。

后来在那里写过很多内容，也遇到过一些让我不太舒服的变化。公开文章被平台未经授权地设成会员可见，关键词被强制插入平台推广链接，读者看到的内容和我写下的内容开始不完全一样。到现在，发文数量也受订阅机制影响。

平台需要盈利，这件事我能理解。

只是内容该写在哪里，我想自己做选择。

以后我会把新的文章放在这个 GitHub 仓库里发布。这里没有额外的会员门槛，也不会在文章里塞进我没有写过的推广链接。文章会有不成熟的时候，也可能改了又改，但它们会按我想要的样子留在这里。

很感谢 [AstroPaper](https://github.com/satnaing/astro-paper) 这个开源博客框架，也感谢 GitHub Pages 提供的托管便利，让我可以把自己的内容放到网上，安安静静地维护下去。

从 CSDN 出发的那些记录没有白写。

这一站，继续写。
